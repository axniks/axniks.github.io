# axniks.github.io

Ratio website built with Flask, Jinja2 templates, and Bootstrap.

## Setup

1. Create and activate a virtual environment.
2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Run the app:

```bash
flask --app app run --debug
```

## Routes

- `/` and `/index.html`
- `/service-partner` and `/service-partner.html`
- `/solicitor-partner` and `/solicitor-partner.html`
- `/investors` and `/investors.html`
- `/privacy` and `/privacy.html`
